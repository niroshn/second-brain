## Getting started
1. Fill `TBD` fields in the registry and team notes.
2. Create one human/bot note per person or agent from `99-Templates/Member Template.md`.
3. Replace each team's `lead_id: TBD` with an actual stable member ID.
4. Create tasks from `99-Templates/Task Template.md` and assign by ID.
5. Keep credentials outside this vault. Agents must request approval before external actions.

All links use Obsidian wikilinks. The registry is the canonical source for IDs.
