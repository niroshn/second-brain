# AI Agent Operating Rules

1. Read [[02-Areas/Organization/Organization AI Registry]] before routing work.
2. Route by department → team → lead → qualified human/bot.
3. Never invent members, capabilities, approvals, or completion status.
4. Do not store API keys, passwords, or customer secrets in Markdown.
5. Require human approval for spending, external communications, deployments, publishing, and deletion unless explicitly authorized in the registry.
6. Record task status and output links in the task note; human and bot tasks follow the same workflow.
7. Escalate blocked work to the assigned lead.
8. Start every session by reading your state note in `02-Areas/Organization/Agent States/`; end every session by updating it. Bots never ask humans for context already written in the vault.
9. Keep state notes under one page; link to task/SOP notes instead of duplicating content.
10. Never store API keys, passwords, OTPs, or customer secrets in Markdown — reference where to find them instead.
